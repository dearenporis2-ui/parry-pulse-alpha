# Effect Sprites

- `spark.png` — optional: could replace the procedural particle dots in particles.js
- `slash.png` — optional: could replace the procedural arc drawn in renderer.js -> drawSwingArcAt()
- `arena_floor.png` — optional: tiled/stretched background for the whole arena
  (if present, replaces the procedural grid drawn in renderer.js -> drawBackground())

These are all optional polish layers — the game is fully playable with the
procedural fallbacks.
