# PARRY-PULSE SFX Drop Zone

Export sound effects from your DAW as **WAV** (best) or MP3, then drop them in
this folder with the **exact names below**. Refresh the browser afterwards.
No code changes are required: each file replaces its built-in synth fallback.

| Filename | Used for | Suggested character |
| --- | --- | --- |
| `shoot.wav` | Revolver fire | Crisp gunshot, short tail |
| `slash.wav` | Regular katana swing/parry attempt | Fast blade whoosh |
| `dash.wav` | Movement dash | Air rush |
| `dash_strike.wav` | Katana left-click dash strike | Aggressive rising slash |
| `weapon_swap.wav` | Changing between katana/revolver | Tiny mechanical click |
| `pistol_shoot.wav` | Pistol pickup fire | Clean semi-auto shot |
| `rifle_shoot.wav` | Rifle pickup fire | Tight rapid-fire crack |
| `gun_pickup.wav` | Collecting any gun pickup | Bright pickup chime |
| `blink.wav` | Blink ability | Sharp spatial warp |
| `pulse.wav` | Kinetic Pulse ability | Expanding low-energy blast |
| `parry.wav` | Enemy-bullet or dash-strike parry | Sharp metallic clang |
| `supercharge.wav` | Teammate bullet supercharge | Large energized clang |
| `hit.wav` | Non-lethal hit | Heavy impact |
| `kill.wav` | Lethal hit | Strong low impact |
| `obstacle_hit.wav` | Bullet hits cover | Concrete/metal tick |
| `round_start.wav` | Round starts | Short alert |
| `round_end.wav` | Round ends | Victory sting |
| `match_end.wav` | Match ends | Larger victory sting |

Recommended export: mono, 44.1 or 48 kHz, under one second for combat SFX.
Leave files out until they are ready—the game stays playable with synthesized
fallback audio.
